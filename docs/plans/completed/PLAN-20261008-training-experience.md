# REQ/PLAN: 训练效率与题库阅读优化

状态：completed（本地源码与验收）；2026-10-08。用户授权：在 question-system 多维度对比后，要求制定优化方案并执行。云端发布是独立阶段。

## 问题与结果

OfferPilot 已有完整训练与复习闭环，但 Dashboard 仍需先进入列表再选题，知识目录缺少关键词检索，参考答案中的代码围栏按普通文字展示。吸收 question-system 的查找、阅读与连续操作体验，保留 OfferPilot 的任务优先级、历史记录和学习数据语义。

## 范围与执行顺序

1. 复核已有时区、并发任务、暂停、增量写入与 Recall 历史回归，记录发布条件。
2. 完成路线优先级 4 的 Dashboard 直接继续、剩余计划参考用时与简洁结束总结。
3. 在现有 Knowledge 页加入题库检索：标题/Topic/分类及有限技术缩写、核心题、未学/薄弱/到期筛选，20 题分页，URL 状态与返回目录上下文。
4. 改善现有答案展示：安全渲染 fenced code，保留普通文本与现有折叠层级；不增加图表或 Markdown 依赖。
5. 校正确定性分提示，记录改述漏匹配基线和核心题后续验收方法。当前评分/关键点/别名不变，120 核心题原子化仍等待 AGENTS.md 要求的迁移验收。

本次执行范围是非破坏性的本地源码优化与验收。生产部署、Supabase 迁移和 Seed 是独立发布阶段；本机未配置 Supabase 连接，不能将本地通过记为云端通过。

## 约束与状态契约

- 复用 `selectNextTrainingTask`：今日队列 → 历史欠账 → 到期复习；跨模块同优先级先继续进行中任务，再按稳定顺序选择。暂停只展示原有任务/暂停前到期债务，不增加暂停期间新任务。
- Dashboard 的参考用时只估算今日剩余已生成任务，不把全部欠账塞进今日预算。初始预算：算法新学 25/复习 15 分钟，知识新学 8/复习 5 分钟；明确为参考值，不声称来自个人统计。
- 今日总结按原计划日期的任务状态计算；暂停日、无任务日不冒充完成训练。历史债务与今日完成分开呈现。
- 检索只使用 catalog 元数据与现有 State，不复制答案、不增加表/API，不写 Attempt/Mastery/任务完成/复习日期。学习/提交操作继续走现有训练入口。
- URL 参数限定为 `q/category/status/core/page`；状态值和页码验证，返回路径只允许本项目 `/knowledge` 查询地址，防止任意跳转。
- Reader 只改变呈现；React 转义内容，不执行 HTML/脚本，未闭合围栏保持原文。原始题库与历史 Attempt 不变。
- 不引入登录外的收藏存储、不整库导入 question-system、不重写调度、不新增语音或 Interview 持久化。

## 验收标准

- [x] 代码块可读、溢出可滚动；普通文字和未闭合围栏不丢失；恶意 HTML 不执行。
- [x] 评分提示不承诺关键词检测能够证明答案正确；保留两套分数和已有计分规则。

## 风险与回滚

URL 导航不能重置提交页状态以外的数据，搜索分页不能隐藏仍待完成的今日任务。新行为均为展示/选择层，可按文件回滚；没有迁移或历史回填。
