# REQ/PLAN: 个人 AI Key 设置

状态：active；2026-10-29。用户要求设置页支持个人 API Key，第一版沿用现有服务方式、模型和现有密钥。

## 范围与约束

- 在设置页提供密钥输入、保存、删除和使用状态；模型和网关沿用服务器当前 `OPENAI_MODEL` / `OPENAI_BASE_URL`。原 `OPENAI_API_KEY` 不迁出服务器，未设置个人密钥时保留原调用路径；个人密钥失效时明确失败，不悄悄转用默认密钥计费。
- 第一版个人密钥保存在当前浏览器 localStorage，按登录用户 ID 隔离，不跨设备同步；页面明确说明本机明文存储及清除方式。除用户自己输入的密钥外，服务器密钥绝不返回给客户端。请求时通过同源 HTTPS 请求头提交，禁止写日志、数据库、URL 和训练历史。
- AI 请求继续通过服务器认证与固定网关，前端不可指定网关或模型；登录账户切换时服务器校验请求头的用户身份，防止旧页面在另一账号下误用密钥。Demo 使用固定独立作用域。
- 覆盖算法分析、八股复核、理解教练和模拟面试追问/总结；维持超时、输出校验、原有 fallback 和训练写入语义。无数据库迁移；真实用户云端验收与生产发布仍依项目既有门槛。
